# Formula 1 Race Monitor
![App Screenshot](/image/demo.png)
A simple python app which fetches and displays F1 race info for upcoming races via FastF1.
This project was inspired by Tom Shaw's F1 Race Replay.
Disclaimer: this project is not affiliated with or endorsed by Formula 1.

# Dependencies
First, you must install the following python packages. They can be installed using pip.
* streamlit 1.65.0
* fastf1 3.8.3
* livef1 1.2.11
* numpy 2.5.4
* matplotlib 3.11.2
* pandas 2.3.3

# Running The Project's UI
To run the web UI, you must run it in your terminal via streamlit, like so:
`python -m streamlit run PATH/TO/FILE/main.py`
